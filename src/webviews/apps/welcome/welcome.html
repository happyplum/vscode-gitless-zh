Git 增压

GitLess 增压 Visual Studio Code 中内置的 Git 功能。它可以帮助您 可视化代码作者身份 通过 Git 逐行追溯注释和代码镜头一目了然， 无缝导航和探索 Git 仓库， 获得宝贵的见解 通过强大 比较命令等等。

GitLess 是一个 开源 扩展。

GitLess 简单地帮助你 更好地理解代码。快速了解谁、为什么以及何时 行或代码块已更改。跳转回历史 获得进一步的见解 至于如何 以及代码为何演变。轻松探索代码库的历史和演变。右潜 看看 GitLess 如何提供帮助！
