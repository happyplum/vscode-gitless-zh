GitLess

Git 增强

GitLess 为 Visual Studio Code 内置的 Git 功能提供增强体验。它可以通过逐行追溯注释和代码镜头，直观呈现代码作者信息； 还可以帮助您顺畅浏览 Git 仓库，并借助强大的比较命令深入了解代码。

GitLess 是一个 开源 扩展。

GitLess 帮助你 更好地理解代码：快速了解某行或代码块由谁、何时以及为何修改。 你还可以回溯历史，深入了解代码的演变过程，轻松探索代码库的发展历程。继续看看 GitLess 能为你做什么！
