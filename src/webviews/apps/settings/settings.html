Git 增压

GitLess 增压 Visual Studio Code 中内置的 Git 功能。它可以帮助您 可视化代码作者身份 通过 Git 逐行追溯注释和代码镜头一目了然， 无缝导航和探索 Git 仓库， 获得宝贵的见解 通过强大 比较命令等等。
